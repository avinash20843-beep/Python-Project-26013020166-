# Python-Project-26013020166-
PERSONAL EXPENSE TRACKER
========================

ABOUT
-----
A terminal-based Python project for recording and reviewing
personal expenses. It uses lists, dictionaries, functions, loops, conditions
and basic text-file handling.

FEATURES
--------
1. Add an expense with an amount, category and description.
2. View all saved expenses.
3. Calculate the total amount spent.
4. View spending totals for each category.
5. Search expenses by category.
6. Save records automatically in a text file.

REQUIREMENTS
------------
- Python 3
- No external libraries are required.

HOW TO RUN
----------
1. Open the Personal_Expense_Tracker folder in VS Code or a terminal.
2. Run this command:

       python expense_tracker.py

   On some systems, use:

       py expense_tracker.py

3. Choose an option from the menu and follow the prompts.

DATA STORAGE
------------
Expenses are stored in expenses.txt in the same folder as the program.
The file is created automatically when the first expense is saved.

NOTES
-----
- Enter a positive amount.
- Category and description are required.
- Search uses the full category name (for example, Food or Travel).
- Keep expense_tracker.py and expenses.txt in the same folder.
